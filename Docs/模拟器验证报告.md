# iPhone 13 Pro Max 模拟器验证报告

[English](Simulator-Validation-Report.md) | **简体中文**

验证日期：2026-08-12

## 环境

- Mac：Apple Silicon macOS 开发机
- Xcode：26.3（17C529）
- Simulator Runtime：iOS 26.3.1（23D8133，arm64）
- 模拟设备：iPhone 13 Pro Max（iPhone14,3）
- App 配置：Debug，最低部署版本 iOS 16.0

## 测试数据

使用 `TestImages/` 中 6 张图片：

- 宽度范围：640–2400 px
- 高度范围：1500–18000 px
- 包含窄图、宽图、短图、长图和超长图
- 文件创建时间与文件名顺序刻意打乱

## 自动化步骤

执行：

```bash
./Tools/RunSimulatorSmokeTest.sh
```

脚本完成以下操作：

1. 创建并启动 iPhone 13 Pro Max 模拟器。
2. 使用 `xcodebuild` 完成 Debug 模拟器构建。
3. 安装 `LongImageViewer.app`。
4. 在主根目录放 2 张图、两个直属子目录各放 2 张图，并加入空子目录、非图片文件和三级目录图片。
5. 通过正式批量添加接口，一次将两个测试图片目录保存为文件夹来源。
6. 再次批量添加相同目录，验证按路径去重且统一同步图片元数据。
7. 验证根目录优先、直属子目录排序，以及非图片和三级目录文件被排除。
8. 在 18 秒内跨目录边界从第一页连续滚动到第六页。
9. 随滚动位置按需生成图片图块。
10. 记录帧统计、图块数、访问页数、内存、目录顺序和四种排序结果。
11. 删除并恢复一张源图，验证目录增量同步。
12. 验证二级侧边栏、子目录定位和当前目录高亮。
13. 将主根目录从 5 个可见条目折叠为 2 个，再展开恢复为 5 个，并确认当前页面不变。
14. 在两个已添加根目录间切换，验证浏览范围与页数同步变化。
15. 删除第二根目录，验证 App 关联和缓存被清理、源文件仍存在。
16. 展示连续选择根目录进度页，验证“继续选择”和统一导入入口可见。
17. 验证密码设置、错误密码拒绝、密码修改、旧密码失效和密码关闭。
18. 验证后台 179 秒无需密码、达到 180 秒要求密码的边界。
19. 安装测试密码后重新启动，验证默认锁定页覆盖主浏览页面。
20. 分别以英文、简体中文、日文启动并验证进程内语言切换。
