# iPhone 13 Pro Max 模拟器验证报告

验证日期：2026-08-11

## 环境

- Mac：Apple Silicon macOS 开发机
- Xcode：26.3（17C529）
- Simulator Runtime：iOS 26.3.1（23D8133，arm64）
- 模拟设备：iPhone 13 Pro Max（iPhone14,3）
- App 配置：Debug，最低部署版本 iOS 16.0

## 测试数据

使用 `TestImages/` 中 6 张图片：

- 宽度范围：640–2400 px
- 高度范围：1500–18000 px
- 包含窄图、宽图、短图、长图和超长图
- 文件创建时间与文件名顺序刻意打乱

## 自动化步骤

执行：

```bash
./Tools/RunSimulatorSmokeTest.sh
```

脚本完成以下操作：

1. 创建并启动 iPhone 13 Pro Max 模拟器。
2. 使用 `xcodebuild` 完成 Debug 模拟器构建。
3. 安装 `LongImageViewer.app`。
4. 将 6 张测试图放入 App 沙盒。
5. 将测试图片目录保存为文件夹来源。
6. 通过正式目录同步流程仅读取图片元数据。
7. 在 18 秒内从第一页连续滚动到第六页。
8. 随滚动位置按需生成图片图块。
9. 记录帧统计、图块数、访问页数、内存和四种排序结果。
10. 删除并恢复一张源图，验证目录增量同步。
11. 保存首屏、滚动中和末页截图。

打开目录后仅生成当前视口附近的 3/30 个图块，证明目录选择不再一次性渲染全部图片。文件夹同步删除回归同样为 60.0 FPS、0 慢帧、5/5 页。真机性能仍应在 iPhone 13 Pro Max 上使用 Instruments 或 Xcode FPS 指标做最终确认；Simulator 数据主要用于发现明显卡顿和功能回归。
