# 长图阅览 App 真机安装指南

[English](Device-Installation-Guide.md) | **简体中文**

适用设备：iPhone 13 Pro Max
最低系统：iOS 16
开发工具：Xcode 26.3 或兼容版本

## 快速安装流程

已经在 Xcode 登录 Apple ID 且 iPhone 开启开发者模式时，只需执行：

1. 打开项目根目录中的 `LongImageViewer.xcodeproj`。
2. 选择 `LongImageViewer` Target → `Signing & Capabilities`。
3. 勾选 `Automatically manage signing`，选择自己的 Team。
4. 用数据线连接并解锁 iPhone 13 Pro Max。
5. 在 Xcode 顶部运行设备中选择该 iPhone，不要选择 Simulator 或 My Mac。
6. 按 `Command + R`。
7. 等待 Xcode 显示 `Build Succeeded`，App 将自动安装并启动。

首次配置或遇到错误时，按下面的完整步骤操作。

## 一、准备工作

1. 确认 Mac 已安装 Xcode。
2. 准备一根可传输数据的 Lightning 数据线。
3. 在 Mac 和 iPhone 上登录同一个 Apple ID 会更方便，但不是强制要求。
4. 免费 Apple ID 可以安装调试版，通常 7 天后需要重新安装；付费 Apple Developer Program 账号的开发签名有效期更长。

## 二、在 Xcode 登录 Apple ID

1. 打开 Xcode。
2. 点击菜单 `Xcode` → `Settings...`。
3. 打开 `Accounts` 标签。
4. 点击左下角 `+`，选择 `Apple Account`。
5. 登录用于签名的 Apple ID。
6. 登录完成后，确认右侧能看到对应的 Team：
   - 免费账号通常显示为 `Personal Team`。
   - 付费开发者账号显示组织或个人开发者 Team。

## 三、连接并信任 iPhone

1. 用数据线连接 iPhone 13 Pro Max 与 Mac。
2. 解锁 iPhone。
3. 如果 iPhone 弹出“要信任此电脑吗？”，点击“信任”并输入锁屏密码。
4. 打开 Xcode 菜单 `Window` → `Devices and Simulators`。
5. 在左侧确认能看到这台 iPhone。
6. 第一次连接时，Xcode 可能显示 `Preparing debugger support`，等待其完成。

如果设备没有出现：

1. 更换支持数据传输的数据线或 USB 端口。
2. 保持 iPhone 解锁。
3. 重新插拔数据线并再次确认“信任此电脑”。
4. 确认 macOS 和 Xcode 支持当前 iOS 版本。

## 四、开启 iPhone 开发者模式

iOS 16 及以上安装开发版 App 需要开启开发者模式：

1. 在 iPhone 打开“设置”。
2. 进入“隐私与安全性”。
3. 滚动到底部，进入“开发者模式”。
4. 打开“开发者模式”开关。
5. 按提示重启 iPhone。
6. 重启解锁后，再次确认“打开”开发者模式并输入锁屏密码。

如果暂时看不到“开发者模式”，先保持 iPhone 连接 Mac，并在 Xcode 中选择设备尝试运行一次，系统通常会显示该入口。

## 五、打开工程并配置签名

1. 用 Xcode 打开项目根目录中的 `LongImageViewer.xcodeproj`。
2. 在左侧项目导航器点击最上方蓝色的 `LongImageViewer` 项目。
3. 在中间 `TARGETS` 列表选择 `LongImageViewer`。
4. 打开 `Signing & Capabilities`。
5. 勾选 `Automatically manage signing`。
6. 在 `Team` 下拉框选择第二步登录的 Team。
7. 检查 `Bundle Identifier`：
   - 默认值是 `com.trae.LongImageViewer`。
   - 如果 Xcode 提示标识已被占用，改为唯一值，例如 `com.你的名字.LongImageViewer`。
8. 等待 Xcode 自动创建开发证书和 Provisioning Profile。

正常状态下，`Signing Certificate` 会显示 `Apple Development`，且页面没有红色错误。

## 六、编译并安装

1. 在 Xcode 顶部设备选择框中，选择已连接的 iPhone 13 Pro Max，不要选择模拟器。
2. 保持 iPhone 解锁。
3. 点击左上角运行按钮，或按 `Command + R`。
4. Xcode 会依次编译、签名、安装并启动 App。
5. 第一次安装可能需要等待设备准备调试服务。

安装成功后，iPhone 桌面会根据设备语言显示 `LongImageViewer`、“长图阅览”或“ロング画像ビューア”。

## 七、处理“未受信任的开发者”

使用部分个人签名首次启动时，iPhone 可能提示开发者不受信任：

1. 打开“设置”。
2. 进入“通用” → “VPN 与设备管理”。
3. 在“开发者 App”下选择对应 Apple ID。
4. 点击“信任”。
5. 确认后重新打开“长图阅览”。

新版本 iOS 在联网校验签名后可能不再显示该步骤。如果设备要求联网，请保持网络可用后重试。

## 八、选择界面语言

App 支持 English、简体中文、日本語。首次启动时跟随受支持的设备语言，其他设备语言环境默认使用英文。

1. 点击右下角“来源”。
2. 点击“语言”。
3. 选择 `English`、`简体中文` 或 `日本語`。
4. App 自有界面会立即刷新并记住选择。

系统“文件”选择器和主屏幕 App 名称仍跟随设备语言。

## 九、导入和使用图片

1. 首次启动点击“浏览图片文件夹”。
2. 在系统“文件”选择器中进入“我的 iPhone”或 iCloud Drive。
3. 选择第一个包含图片的文件夹。
4. 返回 App 后，点击“继续选择”可再次打开系统选择器并添加下一个文件夹。
5. 全部选完后点击“导入 N 个文件夹”，App 会批量保存权限并统一同步。
6. 每个已选择根目录会自动包含根目录图片和直属子目录图片；第三级及更深目录不扫描。
7. 文本、JSON 等非图片文件自动忽略。
8. 重复选择已添加根目录只会更新权限，不会产生重复项。
9. 也可以通过右下角“来源”→“选择图片文件”批量导入单独文件。
10. 上下滑动连续浏览；先显示根目录图片，再按子目录名称顺序显示直属子目录图片。
11. 相邻目录边界保持连续滚动，不会重置浏览器。
12. 顶部左侧显示当前页/总页数，顶部中央显示文件名，右侧显示进程内存。
13. 左下角排序按钮支持：
   - 创建时间顺排
   - 创建时间倒排
   - 文件名顺排
   - 文件名倒排
14. 右下角“来源”可继续添加目录、导入文件或手动同步目录。
15. 在主浏览区单指右划可打开文件夹侧边栏。
16. 侧边栏展示根目录和缩进的直属子目录及图片数量；当前目录会高亮。
17. 点击根目录行右侧箭头可折叠或展开直属子目录；点击根目录名称仍定位到根目录图片。
18. 点击子目录会定位到它的第一张图片，但保留完整连续浏览序列。
19. 根目录行左划可露出“删除”按钮；删除只清理该目录树的 App 内缓存和关联，不影响源目录。
20. 在侧边栏标题或空白区域左划，或点击右上角关闭按钮，可隐藏侧边栏。

目录模式只在 App 内保存屏幕宽度的分块缓存，不会复制或修改源图片。根目录或直属子目录中的图片被修改或删除后，下次同步会更新对应页面。

### 应用密码

1. 点击右下角“来源”→“密码与锁定”。
2. 输入两次相同的新密码；密码长度为 4–64 个字符。
3. 设置成功后，重新启动 App，或离开 App 达到 3 分钟再返回时会显示锁定页。
4. 离开 App 不足 3 分钟再返回，无需重新输入密码。
5. App 处于后台时会立即显示隐私遮罩，避免图片出现在任务切换器快照中。
6. 在锁定页输入正确密码后才能继续浏览。
7. 修改密码时，先输入当前密码，再输入两次新密码。
8. 关闭密码时，先输入当前密码，再点击“关闭应用密码”确认。

不设置密码时，App 会直接进入浏览页面。App 不提供忘记密码找回或重置能力，删除并重新安装 App 也不保证清除系统 Keychain 中的密码，因此设置后需要自行妥善保存。

## 十、常见签名问题

### `Signing for "LongImageViewer" requires a development team`

在 `Signing & Capabilities` 的 `Team` 中选择 Apple ID 对应的 Team。

### `The app identifier cannot be registered`

Bundle Identifier 已被占用。改成一个唯一标识后重试。

### `No profiles for ... were found`

1. 确认已勾选 `Automatically manage signing`。
2. 确认 Mac 能访问 Apple Developer 服务。
3. 在 Xcode `Settings` → `Accounts` 中重新登录 Apple ID。
4. 点击 Team 详情并等待证书刷新。

### `Developer Mode disabled`

按第四节在 iPhone 开启开发者模式并重启设备。

### 免费签名 App 无法继续打开

免费 Apple ID 的调试签名通常 7 天失效。重新连接 iPhone，在 Xcode 中按 `Command + R` 再次安装。

## 十一、安装新版

代码更新后直接连接同一台 iPhone，再次按 `Command + R`。Xcode 会覆盖安装新版本；App 沙盒中的已导入图片通常会保留。删除 App 后重新安装会清空 App 内的图片副本，但系统 Keychain 中的应用密码可能保留。

## 十二、安装后验收

安装完成后依次确认：

1. iPhone 桌面显示本地化 App 名称，App 能正常启动。
2. “来源”→“语言”可切换 English、简体中文、日本語。
3. 首次页面以所选语言显示浏览文件夹入口。
4. 点击后能进入系统文件选择器，并看到“我的 iPhone”和 iCloud Drive。
5. 选择图片目录后，图片按屏幕宽度显示并可连续上下滑动。
6. 顶部显示页码、文件名和实时内存。
7. 左下角按钮能切换四种排序方式。
8. 右下角“来源”能添加目录、选择单独图片及手动同步目录。
9. 添加根目录后会包含直属子目录，但排除非图片和三级目录文件。
10. 根目录最后一张可连续滚动到第一个子目录，再进入后续同级目录。
11. 根目录箭头可折叠并重新展开二级目录，且不改变当前浏览页。
12. “来源”→“密码与锁定”能设置密码。
13. 设置密码后，短暂切到后台并在 3 分钟内返回时无需密码；离开达到 3 分钟后返回会显示锁定页。
