# 长图阅览测试图片

运行以下命令可重新生成全部测试图：

```bash
swift Tools/GenerateTestImages.swift
```

## 测试集

| 文件名 | 尺寸 | 用途 |
| --- | ---: | --- |
| `01_narrow_short_640x1800.jpg` | 640 × 1800 | 窄图放大、短图页边界 |
| `02_phone_medium_1284x5000.jpg` | 1284 × 5000 | iPhone 13 Pro Max 原生像素宽度 |
| `03_wide_medium_2400x6000.jpg` | 2400 × 6000 | 宽图降采样和宽度适配 |
| `10_ultra_long_1284x18000.jpg` | 1284 × 18000 | 超长图切片、内存和连续滚动 |
| `20_wide_short_1800x1500.jpg` | 1800 × 1500 | 横向宽图缩小、快速换页 |
| `Z_tall_narrow_900x12000.jpg` | 900 × 12000 | 窄长图放大和长距离滚动 |

文件修改时间被刻意设置为与文件名顺序不同，用于验证四种排序：

- 创建时间顺排：`20`、`02`、`01`、`10`、`03`、`Z`
- 创建时间倒排：上述顺序反转
- 文件名顺排：`01`、`02`、`03`、`10`、`20`、`Z`
- 文件名倒排：上述顺序反转

每张图包含顶部文件名、原始像素尺寸、连续段落编号、像素高度刻度和底部结束标识。滚动时可据此检查：

1. 图片是否完整铺满屏幕宽度且未被拉伸变形。
2. 同一图片的内部切片是否无缝衔接。
3. 只有不同文件之间出现一条细分割线。
4. 顶部页码和文件名是否在跨页时同步更新。
